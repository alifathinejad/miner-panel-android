# ساخت اپ اندروید پنل ماینر (APK)

## این پروژه چیست؟
همان کد پنل که روی اوبونتو/ویندوز اجرا می‌شود (`miner_panel_core.py` — بدون
هیچ تغییری، عیناً همان فایل) داخل یک اپ اندروید بسته‌بندی شده است. وقتی اپ را
روی گوشی باز کنید، همان سرور Flask در پس‌زمینه بالا می‌آید و یک WebView داخلی
همان داشبورد وب را نشان می‌دهد — دقیقاً همان چیزی که با مرورگر می‌بینید، اما
با آیکون و اجرای مستقل روی خود گوشی.

## چرا اینجا کامپایل نشد؟
ساخت APK به Android SDK، NDK و Gradle نیاز دارد (چند گیگابایت دانلود از
سرورهای گوگل) که در محیط چت من در دسترس نیست. به همین دلیل یک فایل
GitHub Actions (`.github/workflows/build-apk.yml`) آماده کرده‌ام که این کار را
**رایگان و خودکار روی سرورهای گیت‌هاب** انجام می‌دهد — نیازی نیست چیزی روی
کامپیوتر خودتان نصب کنید.

## مراحل ساخت APK

1. یک ریپازیتوری جدید (خصوصی یا عمومی، فرقی نمی‌کند) در GitHub بسازید.
2. همه‌ی فایل‌های همین پوشه (`main.py`, `buildozer.spec`, `miner_panel_core.py`,
   پوشه‌ی `.github`) را در ریشه‌ی همان ریپازیتوری آپلود/پوش کنید.
3. به تب **Actions** ریپازیتوری بروید. ورک‌فلوی «Build Android APK» باید
   خودش بعد از پوش اجرا شود؛ اگر نشد، دستی از همان‌جا (`Run workflow`) اجرایش
   کنید.
4. اولین اجرا معمولاً **۲۰ تا ۴۰ دقیقه** طول می‌کشد (چون باید Android SDK/NDK
   دانلود و کامپایل شود) — طبیعی است، نگران نشوید.
5. بعد از اتمام موفق، در همان صفحه‌ی اجرای Action، پایین صفحه بخش
   **Artifacts** یک فایل به اسم `miner-panel-apk` می‌بینید — آن را دانلود
   کنید؛ همان فایل APK نصبی است.

## نصب روی گوشی
1. فایل APK را به گوشی منتقل کنید.
2. چون از گوگل‌پلی نیست، اندروید یک هشدار «منابع ناشناس» می‌دهد — باید در
   تنظیمات اجازه‌ی نصب از آن منبع (مثلاً فایل‌منیجر یا مرورگر) را بدهید.
3. اپ را نصب و باز کنید؛ چند ثانیه طول می‌کشد تا سرور داخلی بالا بیاید و
   صفحه‌ی لاگین ظاهر شود (یوزر/پس پیش‌فرض همان `admin` / `admin123` است، مگر
   قبلاً عوضش کرده باشید).

## نکاتی که باید روی گوشی واقعی تست/بررسی شوند
این‌ها چیزهایی هستند که چون امکان تست روی دستگاه واقعی برایم نبود، از قبل
تضمین‌شده نیستند و ممکن است نیاز به یک اصلاح کوچک داشته باشند:

- **اتصال HTTP ساده به ماینرها:** از اندروید ۹ به بعد، ترافیک HTTP
  رمزنگاری‌نشده به‌صورت پیش‌فرض مسدود است. چون پنل باید با HTTP ساده به
  دستگاه‌های ماینر توی شبکه وصل شود، اگر دیدید اپ باز می‌شود ولی وضعیت همه‌ی
  ماینرها Offline نشان داده می‌شود، احتمالاً همین مورد است. راه‌حلش افزودن
  `android:usesCleartextTraffic="true"` به مانیفست تولیدشده است — به من
  بگویید تا این را در پروژه اضافه کنم (این مورد بین نسخه‌های مختلف
  Buildozer فرق دارد، بهتر است بعد از دیدن رفتار واقعی اصلاح شود).
- **باتری/پس‌زمینه:** اندروید ممکن است اپ را وقتی صفحه خاموش یا اپ در پس‌زمینه
  است ببندد و مانیتورینگ/هشدار تلگرام متوقف شود. برای رفعش باید بهینه‌سازی
  باتری برای این اپ را در تنظیمات گوشی خاموش کنید (Settings → Apps →
  Miner Panel → Battery → Unrestricted).
- **آیکون اپ:** فعلاً از آیکون پیش‌فرض Buildozer استفاده می‌شود؛ اگر آیکون
  دلخواه دارید (فایل PNG مربعی)، برایم بفرستید تا در `buildozer.spec` تنظیم
  کنم.

## اگر ساخت (Build) با خطا متوقف شد
لاگ کامل خطا را از صفحه‌ی همان Action برایم بفرستید (کپی متن یا اسکرین‌شات)؛
معمولاً یا سر یکی از وابستگی‌های پایتون (`requirements` در buildozer.spec) گیر
می‌کند یا نسخه‌ی SDK/NDK — هر دو با تنظیم دقیق‌تر buildozer.spec قابل رفع‌اند.
